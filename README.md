# rohanjariwala03.github.io

An early attempt (April 2022) at hosting my Flutter portfolio on GitHub Pages as a user site. My current portfolio is at https://rohanjariwala.web.app.

The repo only contains the start of a `flutter build web` output: `index.html`, `manifest.json`, the favicon and app icons. `index.html` loads `main.dart.js`, which was never committed, so the page doesn't render. A later, complete build of the same app (July 2022) is in [rohanjariwalaPortFolio](https://github.com/rohanjariwala03/rohanjariwalaPortFolio) instead.
